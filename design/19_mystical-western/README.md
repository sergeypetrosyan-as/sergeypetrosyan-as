# 19_mystical-western

The design system for this profile, its NEON ARCADE hub and every game in it.
The idea: **a frontier observatory.** You arrive at an engraved desert skyline,
follow a celestial map through the work, and enter each game through an
illustrated tarot card.

Everything is drawn in the **Actual Solutions** brand colours. The names of the
games stay as they are; only how they look changes.

## Files

| File | Job |
|---|---|
| `palette.mjs` | Single source of truth: brand values, derived tints, semantic roles, `toBrand()` remap |
| `tokens.css` | CSS custom properties, generated by `build-tokens.mjs` (`--check` fails if stale) |
| `primitives.mjs` | Canvas 2D drawing primitives: sky, mesa, carved disc / moon phase, cactus, stars, constellation, leather-stamp border, observatory, grain |
| `*.d.mts` | Types so the TypeScript games can import the modules |
| `../../tools/theme/recolor.mjs` | Codemod that moves legacy colour literals onto the brand ramps |
| `../../tools/profile-art/` | Generator for every README banner, separator, tarot card, poster and GIF |

### Roles

`bg` night · `surface` / `surfaceRaised` night+wine · `fg` bone · `accent` red ·
`accentSoft` rose · `line` ember · `paper` bone · `paperInk` ink+wine.
Gameplay: **player = bone** (moonlight), **hostile = red**, **collectible = rose**
(a bright stamped star), **world = tan / wine / umber**, **quiet** background
constellations stay low-contrast and never compete with a collectible.

No violet, no cyan, no neon green. If a legacy colour survives, run it through
`toBrand()`.

## Type

| Face | Use | Never |
|---|---|---|
| **Rye** (OFL, `@fontsource/rye`) | short illustrated titles: a game's name on its title screen or card, a results headline | body text, instructions, numbers, scores |
| **Zilla Slab** 500–700 (`@fontsource/zilla-slab`) | labels, buttons, HUD captions, scores, card numerals | long paragraphs in caps |
| **Public Sans** 400/600 (or the game's existing readable sans) | instructions, descriptions, settings | — |

Scores and timers use tabular numerals (`font-variant-numeric: tabular-nums`).

## Motifs and their jobs

- **Low mesa horizon** anchors a hero or title screen. Keep it in the lower third.
- **Carved sun / moon discs** are focal points; **moon phases** mark transitions
  (section rules, level-complete, pause).
- **Constellation lines** connect related things (projects, level maps, menu paths).
- **Cacti**: sparse, at most three in a frame, for scale.
- **Engraved hatching** and **dust grain** express worn surfaces, always in brand tints.
- **Leather-stamp border**: double rule + dashed stitch + corner diamonds, in ember on dark,
  saddle on paper. Restrained: one per panel.

CSS equivalent of the stamp border:

```css
.stamp {
  border: 2px solid var(--mw-ember);
  border-radius: 10px;
  outline: 1px dashed color-mix(in srgb, var(--mw-tan) 55%, transparent);
  outline-offset: -7px;
  background: var(--mw-role-surface);
}
```

## Motion

One main motion per scene; the loop boundary is seamless; the first frame is a
complete composition. Decorative motion on hosted pages stops under
`prefers-reduced-motion: reduce`.
